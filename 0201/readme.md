# ❄️ SnowFlake (Снежинка)

### 📌 Описание
Этот проект реализует класс `SnowFlake`, который моделирует снежинку внутри квадратной матрицы.  
Снежинка может изменяться с помощью различных методов: растаять, замерзнуть, утолщиться и отобразиться.  

---

## 🚀 Как использовать

### 1. **Создание снежинки**
Снежинка должна быть вписана в квадрат нечетного размера:

```python
flake = SnowFlake(5)  # Создает снежинку размером 5x5
flake.show()  # Показывает снежинку

2. Доступные методы
thaw(steps) – ❄️ таяние (уменьшает размер снежинки, удаляя крайние звездочки).
freeze(n) – ❄️ замораживание (увеличивает размер снежинки и добавляет звездочки).
thicken() – ❄️ утолщение (добавляет звездочки вокруг существующих линий).
show() – 📌 вывод снежинки в консоль.
3. Пример работы
flake = SnowFlake(5)  # Создаем снежинку 5x5
flake.show()

print("\nПосле утолщения:")
flake.thicken()
flake.show()

print("\nПосле заморозки:")
flake.freeze(1)
flake.show()

print("\nПосле таяния:")
flake.thaw(1)
flake.show()



🔧 Требования
Python 3.x
```
